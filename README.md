# iNotes - PHP Notes CRUD App

A simple notes app where you can add, edit, delete and search notes.

## Features
- Add a new note with a title and description
- Edit a note using a Bootstrap modal
- Delete a note with a confirmation prompt
- Search, sort and paginate notes using DataTables
- Success alerts after every action
- Responsive design with Bootstrap 5

## Tech Stack
- Core PHP
- MySQL (MySQLi)
- HTML5, CSS3, JavaScript
- Bootstrap 5
- DataTables

## Setup
1. Install XAMPP and start Apache and MySQL.
2. Open phpMyAdmin, create a database named `notes` and import `notes.sql`.
3. Copy this project folder into `htdocs` and name the folder `crud`.
4. Open `http://localhost/crud/index.php` in your browser.
